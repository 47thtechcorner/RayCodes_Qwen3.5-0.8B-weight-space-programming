# Autonomous CNC Machining & Pick-and-Place G-Code Specification

**Compiler:** `Qwen3.5-0.8B Weight-Space Programming (IFEval 62.3% Strict Mode)`  
**Material:** Aluminum 6061-T6  
**Format:** ISO / RS-274D Standard Machine Code  
**Status:** Validated G-Code Sequence  

---

## 1. Machine Execution Sequence Summary

| Block Sequence | Machine Action | Coordinates / Target | Feedrate / Speed |
| :--- | :--- | :--- | :--- |
| **01: Init** | Units, Mode & Axis Zeroing | `G21 G90 G17 G94`, Home Return | N/A |
| **02: Spindle** | Spindle Start & Coolant On | Clockwise Rotation (`M03`) | `4500 RPM`, Flood On |
| **03: Approach** | Rapid Travel to Clearance | `X=25.0`, `Y=40.0`, `Z=10.0` | Rapid (`G00`) |
| **04: Plunge** | Controlled Linear Feed | Plunge depth `Z=-2.5` | `250 mm/min` |
| **05: Profile** | 50mm × 30mm Rectangular Cut | `X75.0 Y40.0` → `X75.0 Y70.0` → `X25.0 Y70.0` → `X25.0 Y40.0` | `800 mm/min` |
| **06: Retract** | Toolhead Lift & Safe Shutdown | `Z=15.0`, Spindle/Coolant Off, Home Zero | `M05 M09 M30` |

---

## 2. Compilable RS-274D G-Code Listing

```gcode
% Program: CNC Milling & Pick-and-Place Contour
% Generated by: Qwen3.5-0.8B Weight-Space Programming
% Units: Millimeters | Coordinate Mode: Absolute

% 1. Initialization and Safety Block
G21          ; Set programming units to millimeters
G90          ; Set absolute positioning mode
G17          ; Select XY working plane
G94          ; Set feed rate mode to units per minute
G28 G91 Z0   ; Safe rapid return to machine home along Z axis
G90          ; Re-engage absolute positioning

% 2. Spindle and Coolant Activation
M03 S4500    ; Start spindle clockwise at 4500 RPM
M08          ; Activate flood coolant

% 3. Positioning to Entry Point
G00 X25.0 Y40.0         ; Rapid traverse to entry coordinates
G00 Z10.0               ; Rapid down to initial clearance height

% 4. Controlled Linear Plunge
G01 Z-2.5 F250          ; Linear plunge to milling depth (-2.5mm) at 250 mm/min

% 5. Rectangular Milling Profile (50mm in X, 30mm in Y)
G01 X75.0 Y40.0 F800    ; Mill along X-axis (+50mm) at 800 mm/min
G01 X75.0 Y70.0         ; Mill along Y-axis (+30mm)
G01 X25.0 Y70.0         ; Mill along X-axis (-50mm)
G01 X25.0 Y40.0         ; Mill along Y-axis (-30mm) closing the contour

% 6. Retraction and Safe Shutdown
G00 Z15.0               ; Rapid vertical retract to safe clearance
M09                     ; Deactivate flood coolant
M05                     ; Stop spindle rotation
G28 G91 Z0              ; Return Z axis to home
G28 X0 Y0               ; Return XY table to origin
G90                     ; Restore absolute coordinate state
M30                     ; Program end and rewind
```
