## ⚡ Quick Start (Windows PowerShell)

### Step 1: Setup Environment, Download Weights & Register Runtime

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install ollama huggingface_hub

hf download NotCherry/Qwen3.5-0.8B-weight-space-programming-GGUF Qwen3.5-0.8B-Weight-Space-Programming-Q4_K_M.gguf --local-dir models

ollama create qwen3.5-wsp -f Modelfile
```

### Step 2: Run Production Pipeline

```powershell
python main.py
```
